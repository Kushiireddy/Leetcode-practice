# Problems Solved

## 1. Two Sum

- **Problem:** Find two numbers that add up to a target.
- **Concepts:** Lists, indices, loops, nested loops, functions, and conditionals.

## 2.Palindrome Number
- Approach: Convert the integer to a string and compare it with its reverse.
- Concepts: Type conversion, string slicing, conditionals, Boolean values.

## 3. Best Time To Buy And Sell Stock
- Approach: Track the lowest stock price seen so far and calculate the profit at each price, updating the maximum profit when a better one is found.
- Concepts: List traversal, indexing, single-pass algorithm, minimum/maximum tracking, conditionals, greedy approach
