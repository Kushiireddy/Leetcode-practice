# Problems Solved

## 1. Two Sum

- **Problem:** Find two numbers that add up to a target.
- **Concepts:** Lists, indices, loops, nested loops, functions, and conditionals.
- **Approach:** Brute force using nested loops.
- **Time Complexity:** O(n²)
- **Auxiliary Space Complexity:** O(1)

What I learned: How to iterate through a list using indices, check pairs of numbers, and return the indices of the matching pair.
